# Frontend — React + Vite + TanStack

A pnpm workspace. The app lives in `apps/web`; shared UI primitives in
`packages/ui`. See the root [`AGENTS.md`](../AGENTS.md) for conventions.

## Run

```bash
pnpm install
pnpm dev          # http://localhost:3000 (expects backend on :8080)
pnpm typecheck
pnpm lint
pnpm test
```

Point the app at a different backend with `VITE_API_URL`:

```bash
VITE_API_URL=http://localhost:9000 pnpm dev
```

## Structure (`apps/web/src`)

```
task-api/            # the data-access layer for the Task API
  task.api.ts        #   axios instance + interceptors
  task.repository.ts #   calls the API, validates with zod, maps DTO -> domain
  dtos/task.dto.ts   #   zod schemas (wire format)
  mappers/           #   pure DTO <-> domain functions
domain/              # framework-free domain models (Task)
vocabulary/          # enums / shared value types (TaskStatus)
features/tasks/      # the Tasks feature: page, form, hooks, components
shared/
  constants/         #   query keys
  stores/            #   zustand client-state stores (status filter)
routes/              # TanStack Router file-based routes
router.ts            # QueryClient + router
main.tsx             # entry
test-helpers/        # shared test setup + render-with-providers
```

## Data flow

```
component → TanStack Query hook → repository → axios client → backend
                                     │
                                     └─ zod parse + DTO→domain mapping
```

- **Server state:** TanStack Query, keyed by `shared/constants/query-keys.ts`.
- **Client/UI state:** Zustand (`shared/stores`).
- **Forms:** react-hook-form + zod resolver.
- **Styling:** Tailwind CSS v4, primitives from `@template/ui`.

The TanStack Router route tree (`src/routeTree.gen.ts`) is generated by the Vite
plugin on `dev`/`build`; a copy is committed so a fresh checkout typechecks.

## Adding a new API

Copy the `task-api/` folder shape: an `*.api.ts` client, a `*.repository.ts`, a
`dtos/` schema, and `mappers/`. Expose it to components through a TanStack Query
hook under the relevant feature.
